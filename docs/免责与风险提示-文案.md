## 第一节：本软件会用到什么

### 电脑端

    1. 监听 TCP 47820 / UDP 47821
       用途：接收手机发来的音频
       风险：同一局域网内的人可以尝试连接。已防护：需要连接码，同一 IP 连错 5 次锁 60 秒。

    2. 读取系统的音频输出设备列表
       用途：让你选择用哪个音箱或耳机播放
       风险：无

    3. 把音频播放到你选的设备
       用途：这是它的本职工作
       风险：无

    4. 调用 adb.exe（仅在你启用「shell 采集」时）
       用途：启动手机端的采集程序。只做三件事：推送采集程序、启动采集、读取状态。
       风险：adb 是 Android 官方调试工具，能对手机执行命令。
             本软件的全部调用都记录在日志里，你可以用记事本打开逐条核对：
             %LOCALAPPDATA%\NlueMix\nluemix.log

    5. 读写 %LOCALAPPDATA%\NlueMix 目录
       用途：存日志和设置
       风险：无

    ★ 本软件不连接互联网上的任何服务器，不采集、不上传你的任何数据。

### 手机端

    1. 录音（RECORD_AUDIO）
       用途：采集系统内部音频。Android 12 起，采集系统音频必须持有此权限。
       风险：系统状态栏会出现录音提示图标。这是 Android 的强制提示，去不掉。

    2. 录屏授权（MediaProjection）
       用途：这是 Android 唯一允许第三方 App 采集系统音频的官方途径，需要你手动点一次「允许」。
       风险：无。本软件不录屏、不保存画面、不传输画面，只取音频。

    3. 前台服务与常驻通知
       用途：锁屏后继续采集
       风险：通知栏会有一条常驻通知（点击可随时停止）

    4. 后台运行与唤醒锁（WAKE_LOCK）
       用途：锁屏后 CPU 不被挂起，否则音频会断流
       风险：会增加耗电

    5. 网络访问
       用途：把音频发给电脑
       风险：无

    ★ 本软件不读取你的通讯录、短信、照片、位置、已安装应用列表，不采集屏幕内容。

## 第二节：已知问题

    1. 【重要】部分应用的声音默认采不到
       Android 规定：只有在自己清单里声明了 allowAudioPlaybackCapture="true" 的应用，
       它的声音才能被第三方采集；默认值是 false。
       实测：B 站、快手等应用没有声明，所以默认路径采不到它们的声音。
       解法：改用「shell 采集」路径（需要一次性开启手机的无线调试），可采全部应用。

    2. 声音延迟约 200–400 毫秒
       来自蓝牙本身，不是软件问题。不适合打游戏，不适合当 KTV 麦克风。

    3. 不支持 iOS
       苹果不开放系统音频采集接口。

    4. 首次使用需要配置一次
       要么在手机上开一次无线调试，要么用数据线插一次。

    5. 无线调试的端口每次都会变
       手机重启、或重新开关无线调试之后，端口会换成一个新的随机值。

    6. 非 root 手机重启后可能需要重新配置
       这是 Android 的限制，软件绕不过去。

    7. 蓝牙音质由硬件决定
       用什么编码器（SBC / AAC）取决于你的网卡和音箱，软件改不了。

    8. 可能被杀毒软件误报
       本软件含有「局域网传输 + 调试通道」这类特征，可能触发误报。
       代码完全开源，可自行审阅；也可以断网运行来验证它不外传任何数据。

## 第三节：安全风险

    1. 传输未加密
       音频以明文在你的局域网内传输。同一网络下、有能力抓包的人，
       可以还原你正在播放的声音。
       · 在自己家里的网络使用 → 风险很低
       · 在咖啡厅、学校、公司、合租房的公共网络使用 → 请谨慎

    2. 连接码是固定值
       不会自动轮换。知道连接码且在同一局域网的人可以连上。
       已有防护：同一 IP 连错 5 次，锁定 60 秒。

    3. adb 调试通道权限很大
       「shell 采集」需要开启无线调试，而 adb 能对手机执行命令。
       本软件只做上面列出的三件事，但你有权知道这个通道本身的能力边界。
       不使用时可以随时在手机设置里关闭无线调试。

    4. 无障碍权限（仅在你主动启用「自动配置」时）
       无障碍服务在原理上能读取屏幕上的任何内容，包括密码输入框。
       本软件只用它做一件事：操作手机的「开发者选项」页面（开关无线调试、读取端口）。
       不读取任何其他屏幕内容，也不上传任何内容。
       你可以随时在系统设置里关掉它，关掉后手动配置仍然可用。

    5. 最坏情况是什么
       同一局域网内的人，可以往你的音箱里放声音，或者听到你在播放什么。
       攻击者得不到：你的文件、你的密码、你手机或电脑的控制权。
